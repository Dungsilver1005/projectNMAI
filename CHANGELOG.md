# Changelog

All notable changes to the project will be documented in this file.

## [Unreleased]

## [1.1.0] - 2026-11-07

### Added
- Transaction sorting by account ID and amount.
- Transaction search by status.
- Unit tests for transaction sorting and status searching.

## [1.0.0] - 2026-11-07

### Added
- Transaction summary formatting utility.
- Transaction search by account ID.
- Discount calculation utility.
- Fraud detection use-case documentation.
- Pull Request template for standardized code review.
- Transaction sorting by account ID and amount.
- Regression tests for transaction sorting.

### Fixed
- Handle null entries in transaction summaries.
- Prevent invalid transaction amounts from displaying `NaN VND`.
- Correct discount calculations and validate discount percentages.

### Changed
- Improved project documentation and Git workflow.
- Added regression tests for transaction summaries and discount calculations.
- Practiced merge conflict resolution and reverting changes through Pull Requests.

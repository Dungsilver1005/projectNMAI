## [1.0.0] - 2026-11-07

### Added
- Transaction summary formatting utility.
- Transaction search by account ID.
- Discount calculation utility.
- Fraud detection use-case documentation.
- Pull Request template for standardized code review.

## [1.0.1] - 2026-11-07

### Fixed
- Fix whitespace-only transaction amounts displaying `0 VND`.
- Display `-- VND` for invalid whitespace-only amounts.
- Add regression test for whitespace-only transaction amounts.

### Changed
- Improved project documentation and Git workflow.
- Added regression tests for transaction summaries and discount calculations.
- Practiced merge conflict resolution and reverting changes through Pull Requests.
